# Global Tax Reporting Map

Enterprise AI platform for international tax transparency analysis using Retrieval-Augmented Generation (RAG), vector databases, multi-agent orchestration, and conversational AI.

---

## Features

- AI-powered tax intelligence
- Multi-agent reasoning system
- Vector search using FAISS
- FastAPI backend
- Next.js frontend
- Groq LLM integration
- Interactive global transparency map
- Conversational memory system

---

## System Workflow

### Step 1 — User Query
The user asks a question related to international tax transparency, compliance, or reporting standards.

### Step 2 — Semantic Retrieval
The backend converts the user query into embeddings and searches the FAISS vector database for the most relevant tax intelligence documents.

### Step 3 — Multi-Agent Reasoning
Specialized AI agents analyze the retrieved context and generate structured reasoning.

### Step 4 — AI Response Generation
The Groq-powered LLM generates a contextual response using retrieved knowledge and agent outputs.

### Step 5 — Interactive Visualization
Results are displayed through an interactive global transparency map and conversational interface.
